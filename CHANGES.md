# Fixed project

Ця версія зібрана на основі робочого `public/js/appold.js` та поточного `server.js`.

Зміни:
- відновлена єдина логіка налаштувань установок без дубльованих функцій;
- установки завантажуються з таблиці `installations` за `id`;
- назва та тип беруться з PostgreSQL;
- налаштування зберігаються окремо в `installation_settings`, пов'язаній з `installations.id`;
- погодинний графік читається/записується через `installation_schedule` за `installation_id`;
- години мають формат 01 = 00:00–01:00 ... 24 = 23:00–00:00;
- виправлена АРВЧ-розмітка на 24 години;
- деактивація установки зберігається в БД;
- додані API для отримання, створення та оновлення установок;
- стара таблиця `installation_data` кодом не використовується і не змінюється.

Перевірки:
- `node --check public/js/app.js` — OK
- `node --check server.js` — OK
- дубльованих JS-функцій — немає
- усі `$("...")` ID, які використовує JS, присутні в `public/index.html`.
